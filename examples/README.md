# MCP YouTube Search Examples

This directory contains examples to help you get started with the `mcp-youtube-search` package.

## Prerequisites

Before running these examples, make sure you:

1. Have installed the package:
   ```bash
   pip install mcp-youtube-search
   ```

2. Have set up your SerpAPI key either as an environment variable or in a `.env` file:
   ```
   SERP_API_KEY=your_api_key_here
   ```

## Available Examples

### 1. Basic Search Example (`basic_search.py`)

A simple example showing how to search YouTube videos and display the results:

```bash
python basic_search.py
```

### 2. MCP Server Example (`run_mcp_server.py`)

An example showing how to run the MCP server for integration with AI assistants:

```bash
python run_mcp_server.py
```

## Note

These examples are meant to be simple demonstrations of the package functionality. For more detailed usage, please refer to the main README file in the package root directory.
